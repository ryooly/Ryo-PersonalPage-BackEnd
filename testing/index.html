What to expect

Connect opens the socket, waits for the server's ready frame, then asks for microphone access and sends start with the real capture rate. Record begins a new utterance, Stop & Transcribe sends stop and waits for the result frame — the socket stays open, so you can transcribe again without reconnecting.

The server also echoes each transcription to its own console as [transcribe] 1.23s -> …. Utterances are capped at maxSeconds (30 by default) — past that the backend drops the buffer with buffer_full.
